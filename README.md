# BlockScript
Scratch-like visual language for Roblox, no stage/sprites. Modular source, bundled to one script.

Dev (multi-file): `rojo serve default.project.json` -> src/ appears in StarterPlayerScripts.BlockScript.
Ship (single file): `./scripts/build.sh` -> dist/BlockScript.client.luau (wax bundle + darklua minify per .darklua.json). Needs lune, rojo, darklua on PATH. A prebuilt copy is in dist/.
Tests: `tests/harness.lua` loads `src/Lang` under plain Lua with a virtual scheduler; `t_values.lua`, `t_interp.lua`, `t_deep.lua`, `t_place.lua` use it (they were run with Lua 5.5 through lupa, not Luau). The older probes in `tests/probes/` still need a `common.lua` that is not in this copy.

Layout: src/init.client.lua (entry) | src/Lang (engine + blocks) | src/UI (GUI modules).
Rules for bundling: static `require(script.X)` only; no dynamic requires; no GetChildren-based loading.

Status: steps 1-6 in source, plus the full non-rendering Scratch block set. The fix cycle after that (below) was only syntax-checked, not run: no Lua runtime was available. dist/ was rebuilt from the current src (lune 0.10.5, rojo 7.7.0, darklua 0.19.0; wax compile-checked every module). Run under the coreMain sandbox with the real Roblox Full-API-Dump.json, the bundle loads every module and builds the whole GUI (ScreenGui, workspace with the starter scripts, palette, toolbar, console, Save/Load panel); the emulator fired the button handlers and Save produced the program JSON. Actually running a program (Run, output, ask) and dragging blocks were not exercised. The GUI has not been executed in Studio yet.

Fix cycle: Load now enforces the limits in Values.LIMITS (JSON bytes, scripts, blocks, nesting, text and define-name length) before anything is registered; My Block calls left over from rejected imports or deleted defines are dropped from the registry (at most MAX_CUSTOM per program); Program:attach leaves the dragged script in place when its target is stale; renaming a define to an existing define's name is refused with a console message. DESIGN.md holds the palette and the reason for each decoration.

Blocks: everything in Scratch that does not need a stage. Events (when Run clicked, when key pressed, when timer > n, when I receive, broadcast, broadcast and wait), Control (wait, repeat, forever, if, if/else, wait until, repeat until, while, for each, all at once, counter, stop this script/all/other scripts), Sensing (ask/answer, timer, key pressed?, mouse down?, current ..., days since 2000), Operators (all 18, plus `if then else` as a value so a variable can be set to it), Variables, Lists (all 12 incl. item # of and the list as text; index words last/random/all), Output, and My Blocks. Not included because they need a stage or sprites: motion, looks, sound, pen, clones, touching/distance/color sensing, mouse x/y, video, loudness, monitors.

Save/Load: Save shows the program as JSON text (`{"blockscript":1,"scripts":[...]}`) to copy; Load takes pasted text, validates every block against the registry (op exists; hat only first in a script; nothing after a cap; reporters only in slots that accept them), then replaces the workspace.

My Blocks: drag `define` from My Blocks and name it. Write arguments in the name: `(steps)` is a text/number argument, `<flag>` is a true/false argument, e.g. `jump (height) times <fast>`. Put blocks under the define; a block with that name appears in My Blocks, with slots for the arguments, and the `argument` reporters (tap one, pick an argument) read them inside the body. The define's second field, `without pausing`, runs the body without frame yields (up to 0.5 s), like Scratch's "run without screen refresh". Renaming a define renames its calls; renaming an argument renames its reporters.


Antislop pass (rules from github.com/miqdadbadjuber/anti-slop, antislop.md): block text is now dark on the category colours and the Run label is dark on the accent, because white measured 2.4 to 4.5:1; three category colours and the error red were lightened to pass AA; row, toolbar, tab and console button heights are 44px layout units. Remaining failures are listed under Known gaps in DESIGN.md.


Scratch-behaviour pass: a hat that fires while its script runs restarts that script (Run, broadcast; `when key pressed` and `when timer >` are ignored instead); every loop pass gives other scripts a turn (`opts.turn`, default defer + yield) and a frame only ends when the shared CPU allowance is used up; blocks run without a pcall each, so errors unwind the thread and `thread.cur` names the block to mark (My Block recursion is capped at 500 levels, any block nesting at 3000, was 25 and 40); `without pausing` runs up to 0.5 s like Scratch; `all at once` just runs its blocks; `for each` re-reads its count every pass; variables, lists, counter and answer persist between runs (Clear and Load call `interp:resetData()`); numbers print like JS (0.1 + 0.2 shows 0.30000000000000004), booleans compare as 1/0, and text like " 5 ", "0x10" or "Infinity" reads as JS Number() does; `stop other scripts` now ends the run when nothing else is left. dist/ was NOT rebuilt (no lune/rojo/darklua here): run `./scripts/build.sh`. Not run in Luau or Studio; the depth caps in particular are estimates for Luau's stack.

Placement pass (matches scratch-blocks' connection rules): `item of list` and `item # of list` carry `output = "any"` (Scratch's null output) so they fit boolean slots (`Registry:accepts` takes the dragged def as a 4th argument; Validate and the editor both pass it); `forever` is an end block (shape "cap": nothing can follow it, so saves with blocks after a forever no longer load); a C-block with an empty first slot wraps what it lands on: mid-stack drop (`attach` kind "after" + `wrap`), into an occupied C-slot (kind "slot" + `wrap`), or mouth over the top of a script (kind "wrap"). The Program side is covered by `tests/t_place.lua`; the Workspace snapping (`_findTarget`, `_specOfHolder`, `_specOfOp`) is syntax-checked only, and the palette ghost's mouth position is an estimate (one row down, one arm in). dist/ is still not rebuilt.


Plugin pass (step 1 of the plugin task): `src/Plugin/init.lua` is a standalone, requires-free module (Plugin.new, CreateBlock, CreateCategory, GetData); test with `texlua tests/t_plugin.lua`. Step 2 adds `src/Lang/Core/Plugins.lua` (all-or-nothing registration), and `init.client.lua` now ends by returning a Scratch object with `LoadPlugin(plugin) -> error string or nil`, `SetVisibility(boolean)` (false hides the GUI and ignores key/mouse input) and `Plugin` (the class). Tests: `texlua tests/t_loadplugin.lua`. dist/ was NOT rebuilt (no lune/rojo/darklua here): run `./scripts/build.sh`; until then dist/ has neither the plugin module nor the return value. Not run in Luau or Studio.

Look pass (Scratch silhouettes): `src/UI/Shapes.lua` draws each block from Frames after scratch-blocks' renderer: connector tab + notch on stack/C/hat blocks, dome on hats, bowler corners on the define hat (`bowler = true` in the block def), pill reporters, hexagon booleans and empty boolean slots, round fields (dropdowns a darker shade with white text). Categories use Scratch's palette; text on a block is white or dark, whichever contrasts more (`Theme.textOn`, `Theme.whiteBlockText = true` forces white). `forever` has no tab. Rows got 4px top/bottom inset so a nested block has a margin. `tests/t_shapes.lua` runs every block type through BlockView against a fake UI API (`tests/ui_mock.lua`) and checks the structure and hexagon maths; it cannot check how Roblox lays the frames out, so open it in Studio. dist/ is not rebuilt.

Icons: `src/UI/Assets.lua` loads Scratch's flag and loop-arrow PNGs from the GitHub repo with `loadasset(game:HttpGetAsync(BASE .. path))` (`Assets.BASE`, `Assets.PATHS`). A label can embed an icon with `{@flag}`; a C block can set `footerIcon = "loop"`. Without `loadasset` or when a download fails, the icon is left out and the block still works. Files and licence: `assets/`. Test: `texlua tests/t_assets.lua`. dist/ is not rebuilt (run `./scripts/build.sh`).

Luau semantics: see DESIGN.md "Luau semantics". Tests: `texlua tests/t_luau.lua` (also t_values, t_truthy).

Executor support: `scripts/prelude.luau` defines `loadasset(url)` for Roblox executor environments (needs isfolder, makefolder, isfile, writefile, getcustomasset, game:HttpGet; caches PNGs in `Scratch/img/`). `build.sh` prepends it to the bundle after wax + darklua. The script still runs in Roblox Studio: there those functions are missing, the icon load fails inside a pcall, and the icons are left out.

Test (`./test.sh`): waxes (`scripts/build.sh`), copies the bundle to `core/io/obfuscated.lua`, runs `lune run execute` (execute.luau = the coreMain sandbox) and prints a capped summary of `core/io/dumped_output.lua`. AI/LLM: NEVER read `execute.luau` (~580 KB) and NEVER read the whole `core/io/dumped_output.lua` (20,000+ lines, ~700 KB) or `core/io/apidump.json` (8 MB). Read only the summary `test.sh` prints, or capped commands such as `grep -n -m 20 'PATTERN' core/io/dumped_output.lua | cut -c1-200`. Needs lune, rojo, darklua on PATH; the API dump ships as `core/io/Full-API-Dump.7z`, is unpacked for the run and deleted afterwards (`KEEP_DUMP=1` keeps it; needs a 7z extractor or `pip install py7zr`).

gethui: `init.client.lua` parents the ScreenGui to `gethui()` when that function exists and returns a container under a PlayerGui/CoreGui; otherwise (Studio, normal game scripts) it uses PlayerGui. `Workspace:_grab` hit-tests on whichever PlayerGui/CoreGui holds the GUI, so dragging works in both.

Executor functions: see `EXECUTORS.md` (read `sunc.docs.json`, the sUNC function reference, before using any executor function; each one must be checked for existence so Studio keeps working).
